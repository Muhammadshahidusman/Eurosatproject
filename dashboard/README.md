# EuroSAT Land Cover Explorer (dashboard)

A static results dashboard for this project. Your figures and numbers come first,
and a live in-browser classifier is included as an extra.

**Sections:**
1. Hero with headline numbers and four key findings
2. Study area map, an at-a-glance facts table and the methodology flowchart
3. Results summary table, Excel downloads, and training curves
4. Confusion matrices, per-class precision/recall/F1, and the efficiency profile
5. Grad-CAM figure and a test-set gallery
6. Lahore case study: comparison maps, land-cover statistics, and an interactive tile map
7. *Extra:* try the model live (ONNX Runtime Web; downloads only when scrolled into view)
8. Limitations and next steps

Every figure opens full-screen when clicked; the arrow keys move between figures.
Figures with an *Interactive* tab also have a hoverable chart version.

```
dashboard/
├── index.html
├── assets/        style.css, charts.js (SVG charts), app.js
├── data/          metrics.json, lahore.json, figures.json, downloads/*.xlsx
├── models/        cnn.onnx (~4.7 MB), resnet50.onnx (int8)
└── img/           figures/*.webp (your result figures), test-set samples,
                   Grad-CAM overlays, Lahore RGB backdrop
```

## Run locally

The page fetches JSON and ONNX files, so open it through a web server, not `file://`:

```bash
cd dashboard
python -m http.server 8000
# open http://localhost:8000
```

Add `?selftest` to the URL to re-score every gallery image in the browser and
compare the results with the Python predictions. The result is written to
`<pre id="selftest">` at the bottom of the page.

## Deploy

**GitHub Pages (already wired up).** `.github/workflows/deploy-dashboard.yml`
publishes this folder on every push to `main` that touches `dashboard/`.
Enable it once under *Settings → Pages → Build and deployment → Source:
GitHub Actions*. The site is then served at
`https://<user>.github.io/Eurosatproject/`.

**Netlify / Vercel / Cloudflare Pages.** Deploy the `dashboard/` folder as a
static site with no build command.

**Embed in an existing portfolio page:**

```html
<iframe src="https://<user>.github.io/Eurosatproject/"
        style="width:100%;height:900px;border:0;border-radius:12px"
        loading="lazy" title="EuroSAT Land Cover Explorer"></iframe>
```

When embedded in an iframe, the header stops being sticky.

## Update after new results

If you regenerate any figure or workbook in `results/`, refresh the dashboard copies
(this takes a few seconds and needs no dataset):

```bash
python src/build_dashboard.py --figures-only
```

To add a figure, add its `results/` filename to the `FIGURES` list in the script,
then add a `<figure>` block to `index.html`.

## Rebuild everything

Everything in `data/`, `models/` and `img/` is generated by
`src/build_dashboard.py` from the checkpoints in `models/` and the result files
in `results/`:

```bash
python src/build_dashboard.py --data-dir data/Eurosat_Dataset
```

The script:
- recreates the exact training split;
- re-scores both checkpoints on the test set;
- exports them to ONNX and quantises them to int8, calibrating on training images only;
- re-scores the int8 files;
- draws Grad-CAM on test-split images only;
- reads the Lahore per-tile predictions back out of the class-map PNGs.

It needs `torch`, `torchvision`, `onnx==1.16.*`, `onnxruntime`, `openpyxl` and `Pillow`.
